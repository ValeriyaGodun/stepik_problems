# Мини-проекты
Условия данных мини-проектов взяты с курса "Поколение Python": курс для начинающих (https://stepik.org/course/58852/syllabus)

## Общая информация
- Язык реализации: Python 3.10.
- Все сценарии запускаются из консоли и работают с вводом пользователя в режиме диалога.
- Для воспроизведения достаточно запустить соответствующую ячейку в Jupyter Notebook или перенести код в файл `.py`.

## 1. Числовая угадайка
**Назначение.** Игра, в которой пользователю необходимо угадать случайное число в заданном диапазоне.

**Особенности.**
- Валидация ввода: принимаются только целые числа в указанном диапазоне.
- Подсказки «больше/меньше» и учёт количества попыток.
- Возможность начать новую игру без перезапуска программы.

!КАРТИНКА ПРИМЕР РАБОТЫ

## 2. Магический шар 8
**Назначение.** Симулятор «шар судьбы», отвечающий на произвольные вопросы.

**Особенности.**
- Фиксированный набор ответов, соответствующий классической игрушке Magic 8 Ball.
- Поддержка повторных вопросов в рамках одной сессии.
- Нейтральная тональность формулировок.

!КАРТИНКА ПРИМЕР РАБОТЫ

## 3. Генератор безопасных паролей
**Назначение.** Формирование набора случайных паролей с настройкой состава символов.

**Особенности.**
- Настраиваемые длина и количество паролей.
- Включение/исключение цифр, строчных и прописных букв, спецсимволов.
- Опция удаления неоднозначных символов (`il1Lo0O`).
- Генерация выполняется с использованием `random.choice`.

!КАРТИНКА ПРИМЕР РАБОТЫ

## 4. Шифр Цезаря
**Назначение.** Набор скриптов для кодирования и декодирования текста.

**Особенности.**
- Поддержка русского и английского алфавита, сохранение регистра букв.
- Интерфейс с выбором режима (шифрование/дешифрование) и шага сдвига.
- Отдельная реализация для автоматического сдвига каждого слова на его длину.
- Сохранение пробелов, цифр и знаков препинания без изменений.

!КАРТИНКА ПРИМЕР РАБОТЫ

## 5. Угадайка слов (виселица)
**Назначение.** Реализация классической игры «Виселица» с заранее заданным словарём.

**Особенности.**
- Случайный выбор слова и отображение текущего состояния виселицы.
- Учёт уже названных букв и слов, проверка корректности ввода.
- Пошаговое открытие букв и завершение игры при победе или исчерпании попыток.
- Возможность повторного запуска игры без перезапуска сценария.

!КАРТИНКА ПРИМЕР РАБОТЫ
